# Open Deep Research

## 关于 Open Deep Research

Open Deep Research 是一个实验性的、完全开源的研究助手，可自动化执行深度研究并就任意主题生成全面的报告。它旨在帮助研究人员、分析师以及充满好奇心的人生成详尽且来源可靠的报告，免去人工研究的繁琐负担。

### 主要特性
- **自动化研究**：搜索多种来源（网页、学术论文、专业数据库）
- **全面的报告**：生成结构化、引用规范的 markdown 报告
- **多种搜索 API**：支持 Tavily、Perplexity、Exa、ArXiv、PubMed、DuckDuckGo 等
- **灵活的模型选择**：兼容任何支持 `init_chat_model()` API 的 LLM
- **质量评估**：内置评估系统，用于评估报告质量

## 两种研究实现

Open Deep Research 提供两种不同的自动化研究方案，各有独特优势：

### 1. 基于图的工作流实现

**基于图的实现**（`src/open_deep_research/graph.py`）遵循一种结构化的"先规划后执行"（plan-and-execute）工作流：

**特点：**
- **交互式规划**：使用规划器模型生成结构化的报告大纲
- **人工介入**：在执行之前允许对报告计划进行审阅与反馈
- **顺序化流程**：逐个创建章节，并在各轮迭代之间进行反思
- **注重质量**：通过迭代打磨来强调报告的准确性与结构性

**适用于：**
- 对准确性要求极高的高风险研究
- 需要特定结构或定制化的报告
- 希望对研究过程保持掌控的场景
- 学术或专业研究场景

### 2. 多智能体实现

**多智能体实现**（`src/open_deep_research/multi_agent.py`）采用"监督者-研究员"架构：

**特点：**
- **监督者智能体**：管理整体研究流程并汇总最终报告
- **并行研究**：多个研究员智能体同时研究不同章节
- **速度优化**：得益于并行处理，速度显著提升
- **工具专门化**：每个智能体都拥有与其角色匹配的专属工具

**适用于：**
- 快速研究与快速生成报告
- 速度至上的探索性研究
- 不太需要人工监督的场景
- 商业智能与市场研究

## 质量评估

本指南介绍如何使用 pytest 评估系统快速测试和评估 Open Deep Research 所生成报告的质量。pytest 评估系统提供了一种简便的方式，可以：
- 测试两种研究智能体实现（多智能体与基于图的实现）
- 通过丰富的控制台输出获得即时可视化反馈
- 依据 9 项综合标准检验报告质量
- 比较不同的模型配置
- 在 LangSmith 中追踪结果以便分析

### 测试特定智能体
```bash
# 仅测试多智能体实现
python tests/run_test.py --agent multi_agent

# 仅测试基于图的实现
python tests/run_test.py --agent graph
```

## 理解输出结果

### 控制台输出
评估会提供丰富的可视化反馈，包括：

1. **测试配置面板**：显示当前正在测试的智能体与搜索 API
2. **模型配置表**：以格式化表格展示所有模型设置
3. **报告生成状态**：报告创建过程中的实时反馈
4. **生成报告展示**：以 markdown 格式完整呈现报告
5. **评估结果**：
   - 彩色面板中的 **PASSED/FAILED**（通过/失败）状态
   - **报告结构分析**：展示各章节标题的表格
   - **评估理由**：评估器给出的详细说明

### 评估内容

系统依据 9 项质量标准检查报告：

1. **主题相关性（整体）**：报告是否充分回应了输入的主题？
2. **章节相关性（关键）**：所有章节是否都切合主题？
3. **结构与行文**：各章节是否逻辑连贯、浑然一体？
4. **引言质量**：引言是否交代了背景与范围？
5. **结论质量**：结论是否总结了关键发现？
6. **结构元素**：表格、列表等元素是否使用得当？
7. **章节标题**：Markdown 格式是否正确（# 用于标题，## 用于章节）
8. **引用**：每个正文章节是否都有规范的来源引用？
9. **整体质量**：研究扎实、内容准确、行文专业
